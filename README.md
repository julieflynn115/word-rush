# 单词闯关 word-quest

> 覆盖小学到雅思共 9 个阶段的英语单词闯关小游戏，含微信小程序版与 Web 版。

仓库包含两部分：

| 目录 | 内容 |
| --- | --- |
| `src/`、`config/`（根目录） | **微信小程序版**：Taro 4 + React 18 + TypeScript 的选择题闯关小程序 |
| `TypeWords/` | **Web 版**：基于 [TypeWords](https://github.com/zyronon/TypeWords) 的私有部署副本，附带本地化词库与选择题闯关页 `public/quiz.html` |

下面主要介绍小程序版。

## ✨ 特性

- **9 个词库阶段**：小学、初中、高中、大学四级、大学六级、专业八级、商务英语 BEC、托福、雅思，共 32,508 个单词
- **选择题闯关玩法**：每关 10 题，3 颗心，答错扣心，连对可获得额外加分
- **星级评价**：0 错误三星、≤2 错误两星、其余一星
- **错词本**：答错的单词自动收录，支持按阶段重练，答对后自动移除
- **进度持久化**：通关记录、星星数、错词本均保存在本地 Storage
- **9 种专属配色**：每个阶段有独立的渐变色标

## 🎮 页面

| 页面 | 说明 |
| --- | --- |
| 闯关首页 | 9 阶段入口、总进度、累计星星、错词数、继续上次学习 |
| 选关页 | 关卡网格、三星解锁、100 关/页分页 |
| 答题页 | 英译中/中译英随机、4 选项、连对加分、答错震动反馈 |
| 结算页 | 星级、得分、正确率、本关错词、下一关 |
| 错词本 | 按阶段分组错词、删除、重练 |
| 我的 | 学习统计、震动开关、清空错词、重置进度 |

## 🚀 开发

```bash
# 安装依赖
pnpm install

# 微信小程序
pnpm dev:weapp

# H5 预览
pnpm dev:h5
```

## 📦 构建

```bash
# 微信小程序
pnpm build:weapp

# H5
pnpm build:h5
```

构建产物在 `dist/` 目录。

## 🗂️ 目录结构

```
.
├── config/              # Taro 构建配置
├── src/
│   ├── app.config.ts    # 页面与 tabBar 配置
│   ├── app.tsx          # 应用入口
│   ├── assets/          # tabBar 图标等静态资源
│   ├── components/      # 复用组件
│   ├── data/            # 词库数据（按阶段拆分）
│   ├── pages/           # 6 个页面
│   ├── services/        # 词库加载服务
│   ├── styles/          # 主题与变量
│   ├── types/           # TS 类型
│   └── utils/           # 工具函数（闯关逻辑、本地存储）
├── project.config.json  # 微信小程序配置
└── tsconfig.json
```

## 📝 词库数据

词库存储在 `src/data/dicts/` 下，每个阶段一个 JSON 文件，格式为单行字符串：

```
单词\t音标\t核心释义
```

共 9 个阶段，总大小约 1.55 MB，按阶段动态加载，避免首屏加载全部数据。
